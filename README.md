# Overview
This project performs Exploratory Data Analysis (EDA) on customer purchase data using Python.

# Features
- Data Cleaning
- Statistical Analysis
- Histograms
- Bar Charts
- Correlation Heatmaps
- Boxplots
- Insights Generation

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# Installation

pip install -r requirements.txt
